# Release notes

Installers are attached to each [GitHub release](../../../releases). This folder keeps the long-form
notes so they stay readable and linkable from [smflow.co](https://smflow.co).

- [CHANGELOG.md](CHANGELOG.md) — every release, newest first
- `notes/vX.Y.Z.md` — the long-form notes for a single release, when one warrants it

## Versioning

SMFlow uses semantic versioning. Ahead of 1.0, minor versions may change the project file format;
the editor migrates older `formatVersion` projects forward on open, and the release notes call out
any migration that is not automatic.
