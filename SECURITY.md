# Security policy

## Reporting a vulnerability

Please report security issues in SMFlow — the editor, the compiler, the licensing service, or code it
generates — privately to **security@smflow.co**. Do not open a public issue.

Include what you found, how to reproduce it, the SMFlow version, and the impact you believe it has.
You will get an acknowledgement within three business days and an assessment within ten.

Please give us a reasonable window to ship a fix before disclosing publicly. Credit is given in the
release notes unless you'd rather not be named.

## Supported versions

Security fixes land in the current release. Older versions are not patched.
