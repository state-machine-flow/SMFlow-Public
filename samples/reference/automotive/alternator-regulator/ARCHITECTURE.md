# 2020 GM Duramax Alternator ECU Replacement — Reference Architecture
### GM Part Numbers: 84143541 / 23298275 (L5P 6.6L Turbo-Diesel Hairpin Generator)

This document specifies the technical architecture, electrical interface, control algorithms, and safety parameters for an SMFlow-based **Electronic Voltage Regulator (EVR)** designed to act as a standalone **Engine Control Unit (ECU) replacement** for the high-output alternator found on the **2020 GM Duramax (Silverado/Sierra 2500HD/3500HD 6.6L L5P diesel)**.

---

## 1. Problem Statement & Vehicle Application

### The Duramax Swap Problem
The 2020 GM 6.6L Duramax diesel engine utilizes high-output hairpin alternators:
- **GM Part Number 84143541** (220 A high-output primary alternator)
- **GM Part Number 23298275** (150 A / 220 A Delco-Remy / Denso hairpin alternator)

These alternators are engineered for GM's proprietary **Regulated Voltage Control (RVC)** architecture. In a factory vehicle, the Body Control Module (BCM) and Engine Control Module (ECM) communicate to control the alternator via a dedicated 2-pin connector.

When these engines or alternators are transplanted into:
- Classic truck restomods (1967–1987 Chevy C10, K5 Blazer, Squarebody diesel swaps)
- Off-road / pulling rigs and custom tube chassis
- Marine commercial repowers
- Standalone racing builds running standalone ECUs (e.g., Haltech, MoTeC, MaxxECU) that lack GM RVC control logic

**The alternator does not self-regulate.** Without an ECU commanding the turn-on signal, the alternator either completely shuts down (0 A output) or runs in an unstable default state. Simply tying wires to 12V ignition will not regulate the alternator properly and risks overcharging or battery depletion.

The SMFlow controller replaces the missing GM powertrain computer, providing closed-loop voltage regulation, starter cranking protection, thermal derating, and overvoltage latching.

## 2. Electrical Interface & Terminal Specifications

The 2020 Duramax alternator connects via a heavy B+ post and a 2-pin sealed connector (Yazaki/Metri-Pack):

```
+-----------------------------------------------------------------------+
| 2020 Duramax Alternator (84143541 / 23298275)                         |
|                                                                       |
|   Pin A: L-Terminal (Generator Turn-On / 128 Hz PWM Command)  <-------+ (From MCU GP16)
|   Pin B: F-Terminal (Field Monitor / 128 Hz PWM Feedback)     ------->+ (To MCU GP15)
|   B+ Terminal (M8 Battery Stud)                               ------->+ (To +12V Bus)
|   Casing Ground (Engine Bracket)                              ------->+ (GND)
+-----------------------------------------------------------------------+
```

### Pin A: L-Terminal (Turn-On & Duty Command)
- **Signal**: 128 Hz PWM signal driven by the controller.
- **Physical Layer**: Open-drain N-channel MOSFET with internal/external 1 k$\Omega$ pull-up to +12V.
- **Function**: Commands the internal solid-state regulator's target voltage setpoint.
- **GM RVC Voltage Relationship**:
  Per GM technical documentation, the internal regulator converts the commanded duty cycle into the following generator setpoint voltages:

| Commanded Duty Cycle | Generator Target Voltage | GM RVC Operating Mode |
| :---: | :---: | :--- |
| **0% – 9%** | *Field De-energized / Standby* | Cranking lockout, engine stall, safety fault |
| **10%** | **11.00 V** | Low diagnostic floor |
| **20%** | **11.56 V** | Minimum float mode (`DutyFloat` default) |
| **30%** | **12.12 V** | Low maintenance mode |
| **40%** | **12.68 V** | Fuel Economy mode / Thermal Derate (`DutyDerated`) |
| **50%** | **13.25 V** | Battery maintenance mode |
| **60%** | **13.81 V** | Standard float charging |
| **70%** | **14.37 V** | Normal absorption mode |
| **80%** | **14.94 V** | Boost / Heavy charge mode (`DutyBoost`) |
| **90%** | **15.50 V** | Maximum cold-cranking recovery ceiling |
| **> 90%** | *Saturated / Clamp* | Restricted in software to prevent field coil overheating |

### Pin B: F-Terminal (Field Duty Feedback)
- **Signal**: **128 Hz PWM pulse train** generated by the alternator regulator.
- **Operating Duty Range**: Roughly **5% to 99% duty cycle**.
- **Function**: Reports the actual excitation current flowing through the rotor winding, indicating electrical/mechanical load on the engine.
- **Diagnostic Usage**:
  - Normal operation: 5%–99% duty cycle confirms alternator excitation and rotation.
  - Abnormal (< 5% when commanded, or > 99% under light load): Indicates belt slippage, open rotor winding, or diode short.

## 5. Voltage Regulation Strategy

### Why Two-Level Hysteresis Matches GM RVC Dynamics
Rather than implementing a PID loop with integral windup hazards, the controller utilizes a **two-level hysteretic controller**:
1. **Rotor Inductive Filtering**: The Duramax alternator rotor has an electrical time constant $\tau = L/R \approx 70\text{ ms}$. Because the 128 Hz PWM period (7.8 ms) is an order of magnitude faster, the rotor field coil acts as a physical continuous filter, converting the PWM command into steady DC field current.
2. **Hysteresis Deadband**:
   - When $V_{bat} < 14.15\text{ V}$ (`VTargetLow`), the controller commands **Increase L** (`DutyBoost = 0.80`, corresponding to **14.94 V**).
   - When $V_{bat} > 14.25\text{ V}$ (`VTargetHigh`), the controller commands **Decrease L** (`DutyFloat = 0.20`, corresponding to **11.56 V**).
   - The 100 mV deadband ($14.15\text{ V} \to 14.25\text{ V}$) eliminates PWM chatter.

## 6. Thermal Derating & Protection

High-output 220A alternators generate substantial internal heat at low engine idle speeds when cooling fan airflow is limited:
- **Normal Zone ($T < 105.0^\circ\text{C}$)**: Full excitation available (up to 80% / 14.94 V).
- **Derating Zone ($105.0^\circ\text{C} \le T \le 130.0^\circ\text{C}$)**: Excitation duty clamped to `DutyDerated = 0.40` (commanding 12.68 V, GM Fuel Economy mode). This reduces rotor $I^2R$ power dissipation by over 60%, arresting stator and diode pack temperature rise.
- **Critical Shutdown Zone ($T > 130.0^\circ\text{C}$)**: Latches safety shutdown, forcing field PWM to 0.00% to prevent diode desoldering.

### Software Protections:
- **Overvoltage Protection**: Trips at $V_{bat} > 15.60\text{ V}$, zeroing field PWM immediately.
- **Cranking Lockout**: 2.0s startup delay prevents alternator counter-torque while the starter cranks the high-compression 6.6L diesel.
- **Failsafe De-Excitation**: Defaults to 0.00% duty cycle on fault, reset, or ignition removal.

### External Hardware Protection:
- **Load Dump Suppression**: High-energy TVS diode (ISO 7637-2 Pulse 5a, 87 V clamp) on the +12V power feed.
- **Reverse Battery Protection**: Series P-channel MOSFET on the board supply input.
- **ADC Clamping**: Dual BAT54S Schottky diodes clamping GP26 and GP27 between GND and 3.3V.
